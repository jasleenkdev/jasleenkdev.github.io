Projects

FirstPR

PyTorch, BigQuery, FastAPI, Groq

I built this to help CS students find a first open-source contribution. It matches beginner-friendly repos and specific issues to your skills, interests and available time, and explains why using real signals. Under the app is a benchmark where I rebuilt recommender systems in historical order, from popularity and matrix factorisation up to SASRec, LightGCN and LLM rerankers, and scored them all on the same split. The app runs whichever one actually won. On 14.2k real first-time contributors, its top 20 contained the project they went on to join 24.6% of the time, 12× better than recommending popular repos.

Agentic Code Intelligence

Python, embeddings, vector search, MTEB

You type a question in plain English and it finds the right piece of code, running entirely on a laptop CPU with no API calls. I built it for the Samsung PRISM GenAI Hackathon, where it reached the final round. On the CoIR APPS benchmark it scored 0.866 NDCG@10, matching a model three times its size, and I only tuned on the training split. It also searches a codebase across git versions: it re-embeds only the files that changed (470 seconds down to 0.8) and groups the same function across versions.

Arbiter

SUMO, PyTorch, PyTorch Geometric, Stable-Baselines3, React + TypeScript

I wanted to know what happens when you swap fixed-timer traffic lights for AI agents that each only care about their own junction. In my simulation the whole network got 53% worse, because every agent’s gain was paid for by a neighbouring junction with nobody defending it. I then tried six ways of coordinating them, and none beat the plain timer overall. Each one just moved the damage somewhere else, and working out why is the actual result. The live page streams one simulated run of the best setup.

Research Copilot

Python, LangChain, LangGraph, arXiv

A research assistant where four AI roles split the work on one question. A supervisor decides what happens next, a researcher searches arXiv, a writer drafts the answer, and a critic checks that every paper cited really exists. I built it phase by phase to learn LangChain and LangGraph, from a single chain to a multi-agent graph with human approval, streaming, retries, and an evaluation setup that scores repeated runs with confidence intervals instead of trusting one good run.

recsys-go

Go, PostgreSQL + pgvector, Qdrant, Kafka, Redis, Ollama

A GitHub repo recommender built as a systems exercise more than a model one. Starring or viewing a repo fires an event through Kafka that recomputes your taste vector, so the next page load shifts. Search is grounded: answers come only from README chunks that clear a relevance threshold, and if nothing is relevant enough it says so instead of guessing. A brand-new user gets a clearly labelled popular-repos fallback. It runs on 600 real repos and 4,690 README chunks.

CoProperty team project

React, Django REST, Solidity, Hardhat, Web3.py

Fractional real estate on a blockchain. A property is split into tokens, you buy a share, rent is paid out to token holders in proportion to what they own, and holders can vote on proposals. A Django API talks to the Solidity contract through Web3.py, and the React frontend uses wallet login. It runs on a local test blockchain, so it’s a working prototype, not something handling real money. Built with a team; I worked on the Django API and the Web3 service that mints the tokens.

Multiplayer Jigsaw team project

Elixir, Phoenix Channels, JavaScript

A jigsaw puzzle in the browser that you can solve with friends. Pick an image and a difficulty (9, 25 or 100 pieces), share the link, and everyone sees pieces move live. We built it as a team to learn Elixir and Phoenix. There’s no database: moves are broadcast over Phoenix Channels, and the shared channel is the source of truth. A small Python script cuts every image into pieces for every difficulty automatically.
